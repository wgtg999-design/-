# 테스트 사이트 안내

대표님이 요청한 시험용 이름·시행일·사업자 표시 및 개인정보 안내입니다. 실제 운영자 정보, 실제 사업자 등록번호 또는 고객센터로 오해되지 않도록 모두 **테스트 전용**으로 표시합니다.

- 쇼핑몰명: YOUR LABEL
- 표시 시작일: 2026년 10월 14일
- 상호·담당자: 테스트 운영자·테스트 담당자
- 사업자등록번호·통신판매업 신고번호: 테스트용·미등록
- 주소: 온라인 시험 환경·실제 사업장 없음
- 연락처: 테스트용·연락처 미운영
- 예시 이메일: support@example.invalid — 메일을 받지 않는 주소
- 이용약관: `/policies/terms`
- 개인정보 안내: `/policies/privacy`

이메일 인증에는 Clerk에서 확인한 실제 이메일이 사용됩니다. 가입 화면의 이름·연락처·배송지에는 가상정보만 입력해야 합니다. 시험 이름 “테스트 회원”, 시험 연락처 “00000000”으로 입력값을 확인할 수 있습니다.

## 테스트 모드와 저장 범위

`site-mode.json`의 `mode`가 `test`일 때만 시험용 약관 기본값을 사용합니다. 서버 환경변수 `STORE_SITE_MODE`가 있으면 파일보다 우선합니다. 정확히 `test`인 값만 시험 모드를 켜며 `live`, 알 수 없는 값 또는 빈 값은 시험 기본값을 제공하지 않습니다. 브라우저 요청, 주소나 인증 키의 종류로 시험 모드를 추측하지 않습니다.

DB에 운영 설정이 저장되어 있으면 저장된 약관을 먼저 읽습니다. 저장된 설정을 덮어쓰거나 마이그레이션하지 않습니다. 저장된 설정이 비어 있거나 잘못되었으면 시험 기본값으로 바꿔서 가입을 열지 않습니다. DB 연결이 없는 상태에서도 공개 시험 안내 페이지는 볼 수 있지만, 실제 회원 저장에는 DB 준비·인증·동의·버전·요청 출처 검사가 필요합니다.

테스트 모드에서 DB 연결이 완전히 없거나 연결된 DB의 사용자 테이블이 0개일 때만 원본 시안 상품 4개를 읽기용으로 표시합니다. 재고와 회원·주문을 생성하지 않습니다. 일부 연결 설정만 있거나, 기존 테이블·잘못된 저장 데이터·연결 장애가 있으면 시안 상품으로 대체하지 않고 오류를 안내합니다. 기존 저장 상품을 정상 조회할 수 있으면 항상 해당 상품을 우선합니다.

테스트 모드에서는 기존 주문 설정의 값과 관계없이 서버가 주문 접수를 중지 상태로 취급합니다. 실제 입금·배송을 받지 않으며 관리자 주문 설정에서도 접수를 켤 수 없습니다. 원본 Sites 서버의 기본값·권한 검사·데이터에는 적용하지 않습니다.

## 실제 운영으로 바꾸기 전

실제 약관·개인정보 처리방침, 운영자와 연락 가능한 고객지원 정보, 서비스 계약·저장 지역 및 보유·삭제 절차를 확인해야 합니다. 회원 탈퇴·자동 삭제·자동 백업·상시 감시 기능은 준비됐다고 약속하지 않습니다.

`STORE_SITE_MODE=live`로 바꾸고 재배포해도 DB에 저장된 시험 데이터를 자동 삭제하지 않습니다. 서버는 시험 문서의 표식을 인식하여 해당 문서가 실제 가입 안내로 재사용되는 것을 막습니다. 관리자가 확인한 실제 안내로 교체하기 전에는 가입 안내를 준비 중인 상태로 유지합니다. 코드 복구와 회원·주문·이미지 삭제 또는 복구는 별개의 작업입니다.

실제 운영 설정을 연결했다는 뜻으로 문서나 로컬 검증 결과를 보고하지 않습니다. Vercel의 최신 배포와 Clerk·Turso·R2의 실제 연결 상태는 별도로 확인해야 합니다.
