# YOUR LABEL 이용약관 — 테스트 전용
시행일: 2026년 10월 14일

테스트 전용 안내
이 문서는 쇼핑몰 화면과 회원가입 기능을 시험하기 위한 이용안내입니다. 사업자 정보는 가상입니다. 실제 판매·입금·배송을 진행하지 않으며, 이름·연락처·배송지는 가상정보만 입력해야 합니다. 로그인 시 이메일 인증은 실제 로그인 서비스인 Clerk에서 처리됩니다. 실제 운영 전에 운영자 정보와 이용조건을 확정한 약관으로 교체해야 합니다.

### 제1조 (목적)
본 안내는 테스트 운영자가 운영하는 온라인 패션 쇼핑몰 YOUR LABEL의 화면 및 기능을 시험하는 절차를 설명합니다. 현재는 실판매용 쇼핑몰이 아닙니다.

### 제2조 (정의)
1. “몰”은 의류 및 패션잡화 상품 화면을 제공하는 테스트 사이트를 말합니다.
2. “이용자”는 화면과 기능을 확인하는 테스트 참여자를 말합니다.
3. “회원”은 Clerk에서 이메일을 인증하고 이름·연락처와 동의사항을 저장한 테스트 계정을 말합니다.
4. 회원가입 없이 상품 화면을 확인할 수 있으나, 회원정보와 주문 내역은 로그인한 본인만 확인할 수 있습니다.

### 제3조 (안내의 게시와 변경)
1. 본 이용안내와 개인정보 안내를 회원가입 화면 및 별도 안내 페이지에서 확인할 수 있습니다.
2. 테스트 안내가 변경되면 가입 화면에 변경된 내용을 표시합니다. 서버가 동의 버전의 변경을 확인하면 새로고침 후 다시 동의해야 합니다.
3. 실제 운영용 약관은 운영 전에 별도로 확정하여 게시해야 합니다.

### 제4조 (테스트 기능)
1. 상품 목록·분류·검색·상세 및 장바구니 화면을 시험할 수 있습니다.
2. 이메일 인증 후 테스트 회원정보를 저장하고 본인의 정보를 수정할 수 있습니다.
3. 실제 주문 접수는 중지되어 있습니다. 배송, 실결제, 송금 및 환불이 이루어진 것으로 표시하지 않습니다.
4. 관리자 기능은 서버에서 권한을 확인한 관리자만 사용할 수 있습니다.

### 제5조 (테스트 회원가입)
1. 회원가입에는 Clerk에서 확인한 이메일 로그인, 이름·연락처 입력 및 이용안내·개인정보 안내 동의가 필요합니다.
2. 이름·연락처는 실제 고객정보 대신 가상의 테스트 값을 사용해야 합니다. 예: 이름 “테스트 회원”, 연락처 “00000000”.
3. 인증되지 않은 요청이나 타인의 신원으로 가입하는 요청은 허용하지 않습니다.
4. 본 테스트에 만 14세 미만의 실제 이용자를 모집하지 않습니다. 연령 확인 및 법정대리인 동의 기능은 구현되어 있지 않습니다.

### 제6조 (회원정보의 변경)
로그인한 회원은 내 계정에서 본인의 이름·연락처를 수정할 수 있습니다. 이메일 인증과 비밀번호 관리는 Clerk 로그인 서비스에서 제공합니다. 다른 사람의 회원정보와 주문을 조회·수정해서는 안 됩니다.

### 제7조 (탈퇴와 삭제)
쇼핑몰 회원정보의 자동 탈퇴·삭제 화면은 아직 구현되어 있지 않습니다. 테스트 데이터 정리가 필요하면 테스트 담당자가 로그인 서비스와 쇼핑몰 DB를 각각 확인하여 별도로 처리해야 합니다. 자동 삭제나 자동 백업을 제공한다고 약속하지 않습니다.

### 제8조 (상품과 주문 화면)
상품명·사진·가격은 시안일 수 있습니다. 장바구니 및 주문서 화면은 기능 확인용이며 현재 주문 접수는 중지되어 있습니다. 실제 주소나 실제 수령인 연락처를 입력하지 마세요.

### 제9조 (계약의 성립)
현재 테스트 화면의 상품 선택이나 장바구니 저장만으로 실제 구매계약이 성립하거나 실제 판매가 이루어지지 않습니다. 운영 개통 전에 상품·재고·주문·입금·배송 조건을 별도로 확정해야 합니다.

### 제10조 (대금 결제)
현재 서버에 구현된 주문 방식은 무통장 입금 주문 접수입니다. 이 테스트 사이트에서는 접수가 중지되어 있으며 입금할 계좌를 제공하지 않습니다. 신용카드·간편결제, 자동 결제 및 자동 환불 송금은 연결되어 있지 않습니다.

### 제11조 (상품의 공급 및 배송)
현재 실제 출고나 배송을 진행하지 않습니다. 택배사 실시간 조회도 연결되어 있지 않습니다. 실판매 개통 전에 실제 배송비·출고일·배송업체 및 고객지원 정보를 안내해야 합니다.

### 제12조 (청약철회 및 반품)
실판매 개통 시 소비자의 법정 청약철회 및 환급 권리를 보장하는 정책이 필요합니다. 원칙적인 7일 청약철회와 표시·광고 및 계약 내용과 다른 상품에 관한 구제는 관계 법령에 따릅니다. 현재 테스트에서는 실제 판매·반품·환급을 처리하지 않습니다.

### 제13조 (교환 및 환불)
주문 상태의 취소·반품 처리 기능은 실제 송금을 수행하지 않습니다. 실운영 시 실제 환불 후 관리자가 환불 완료를 기록해야 합니다. 별도의 교환 신청 기능은 구현되어 있지 않습니다.

### 제14조 (적립금 및 쿠폰)
적립금·쿠폰 발급과 사용 기능은 현재 구현되어 있지 않습니다. 테스트 이용으로 금전적 혜택이 발생하지 않습니다.

### 제15조 (개인정보 보호)
실제 로그인 이메일과 테스트 회원정보가 처리되는 방법은 별도의 테스트 개인정보 안내를 확인해야 합니다. 운영용 개인정보 처리방침은 실제 운영자와 서비스 설정을 확인한 뒤 확정해야 합니다.

### 제16조 (운영자의 역할)
테스트 담당자는 화면과 기능을 점검합니다. 현재 고객센터 주소와 사업자 정보는 시험 표시용이며, 운영용 고객지원 창구가 아닙니다.

### 제17조 (이용자의 의무)
타인의 정보 입력, 타인 계정의 부정 사용, 시스템 침입 및 서비스 방해, 개인정보·지식재산권 침해를 금지합니다. 테스트 중 실제 고객 개인정보를 입력하지 마세요.

### 제18조 (콘텐츠)
상품 사진·로고·문구 등은 정당한 권리자의 허락 범위에서 사용해야 합니다. 화면 시안은 제3자의 사진·로고·소스를 복제할 권리를 부여하지 않습니다.

### 제19조 (문의와 분쟁)
현재는 테스트 담당자와 기능 점검 사항을 확인하는 단계입니다. 실판매 개통 시 실제 문의 창구와 분쟁 해결 절차를 안내해야 하며, 소비자의 법정 구제 권리를 제한해서는 안 됩니다.

### 제20조 (준거법)
본 안내의 해석과 실제 운영에 필요한 사항에는 대한민국 법령을 적용합니다. 이 테스트 문서는 실운영을 위한 법률 검토 완료를 의미하지 않습니다.
