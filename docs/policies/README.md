# 회원가입 운영 문서

`terms-submitted.md`는 대표님이 2026-10-14 보내주신 이용약관 원문입니다. 시행일과 사업자 정보가 미정인 초안으로 보관하며, 고객용 약관으로 게시하거나 DB의 운영 설정에 저장하지 않았습니다. 파일이 있다는 이유로 회원가입을 개통하지 않습니다.

이후 대표님이 테스트용 가상 운영 정보와 개인정보 안내 작성을 요청하여 `terms-test.md`, `privacy-test.md`를 별도로 준비했습니다. Vercel의 명시적인 시험 모드에서 공개하며 실제 운영용 문서로 사용하지 않습니다. [시험 모드 안내](../../deploy/vercel/TEST-SITE.md)를 확인하세요.

공개 전에 대표님이 확정할 값은 쇼핑몰명, 시행일, 상호, 대표자명, 사업자등록번호, 통신판매업 신고번호, 사업장 주소, 고객센터 연락처, 이메일입니다. 본문 제1조의 `상호명`과 `쇼핑몰명`도 실제 명칭으로 바꿔야 합니다. 기존 화면의 `YOUR LABEL`은 임시 브랜드명입니다.

개인정보 처리방침 및 가입 시 개인정보 수집·이용 안내는 아직 전달받지 않았습니다. 처리 목적·실제 수집 항목·보유 기간·수탁자 등 실제 운영과 서비스 연결을 확인한 내용을 준비해야 합니다. 이 저장소는 운영자의 실제 정보나 문구를 임의로 채우지 않습니다.

아래는 약관 문구를 확정할 때 소스와 맞춰 확인할 사항입니다. 현재 구현과의 대조이며 법률 검토 완료를 의미하지 않습니다.

| 조항 | 현재 구현 | 확정 시 확인 |
| --- | --- | --- |
| 제8조·제10조 결제 | 무통장 입금 주문 접수, 관리자 실제 입금 확인 | 카드·간편결제·여러 결제수단 선택이 제공되는 것처럼 게시하지 않도록 문구를 맞춥니다. |
| 제7조 회원탈퇴 | 쇼핑몰 회원정보·주문 보존을 포함한 마이페이지 탈퇴 절차 미구현 | 실제 탈퇴 접수·처리 방법과 고객센터 연락처가 필요합니다. Clerk 로그인 계정 삭제와 쇼핑몰 회원·주문 정보 처리는 별개입니다. |
| 제13조 교환 | 마이페이지 취소·반품 요청 구현, 교환 전용 신청·처리 미구현 | 교환은 실제 고객센터 처리 절차를 정하거나 전용 기능을 구현한 뒤 안내합니다. |
| 제14조 적립금·쿠폰 | 적립·발급·할인 기능 미구현 | 기능과 실제 운영정책을 마련하기 전에는 제공 중이라고 표시하지 않습니다. |
| 제5조 보호자 동의 | 법정대리인 확인·동의 절차 미구현 | 대표님이 실제 가입 대상과 처리 방식을 정해야 합니다. 임의로 가입 대상이나 동의 방식을 결정하지 않습니다. |
| 제9조 알림 | 사이트 내 본인 주문 내역 | 자동 이메일·문자 발송을 연결하지 않은 상태에서 발송 완료로 안내하지 않습니다. |
| 제11조 출고 안내 | 주문 화면 배송비, 관리자 등록 배송 상태·송장 | 실제 출고 예정 안내를 확정해야 합니다. 실시간 택배 조회는 연결되지 않았습니다. |

고객 화면은 `/signup`, 실제 운영 설정 저장 위치는 `/admin/orders`의 **운영 설정**입니다. 완성된 약관과 개인정보 안내를 저장하고 실제 인증·DB 연결을 확인해야 가입을 열 수 있습니다. 주문 접수에는 실제 입금 안내·고객센터·배송/반품 안내·재고 설정도 필요합니다.
