# YOUR LABEL 개인정보 안내 — 테스트 전용
시행일: 2026년 10월 14일

### 1. 테스트 사이트와 입력 원칙
이 사이트는 테스트 운영자가 쇼핑몰 화면과 기능을 점검하기 위한 시험 환경입니다. 실판매와 실제 주문 접수는 중지되어 있습니다. 이름·연락처·배송지는 가상정보만 입력하세요. 로그인 이메일은 인증 가능한 실제 이메일을 사용하며, Clerk 로그인 서비스로 전달됩니다. 이 안내는 법률 검토를 마친 실운영용 개인정보 처리방침이 아닙니다.

### 2. 로그인에서 처리하는 정보
Clerk가 로그인 이메일, 이메일 인증 상태, 로그인 세션 및 계정 인증에 필요한 정보를 처리합니다. 이메일과 비밀번호를 이용하는 경우 비밀번호·재설정·이메일 인증은 Clerk가 담당합니다. 쇼핑몰 자체 DB에는 비밀번호를 저장하지 않습니다. 쇼핑몰 서버는 인증된 사용자 ID와 이메일을 확인합니다. 관리자 권한은 확인된 신원과 서버 설정 및 저장된 관리자 ID를 사용하여 판별합니다.

### 3. 테스트 회원 등록에서 처리하는 정보와 목적
Clerk에서 확인한 사용자 ID·이메일, 입력한 이름·연락처, 동의한 안내 버전 및 가입 시각을 쇼핑몰 DB에 저장합니다. 목적은 로그인 계정과 회원정보 연결, 본인 회원정보 조회·수정, 회원가입 동의 확인과 기능 점검입니다. 회원 가입을 선택하지 않고 상품 화면을 볼 수 있습니다. 필수 가입정보와 동의를 제공하지 않으면 쇼핑몰 회원 등록은 완료되지 않습니다.

### 4. 장바구니와 주문 관련 정보
장바구니의 상품·사이즈·수량, 찜 목록과 표시 언어는 이용 중인 브라우저의 localStorage에 저장될 수 있습니다. 주문 재시도 중복 방지용 정보는 sessionStorage에 저장되며 주문 입력 내용에 배송지·연락처가 포함될 수 있습니다. 로그인 세션은 Clerk가 관리하는 쿠키를 사용합니다. 관리자·회원·주문 정보의 유일한 저장소로 브라우저를 사용하지 않습니다.
현재 주문 접수는 중지되어 있습니다. 주문 기능을 추후 시험·개통하는 경우 주문자 사용자 ID, 상품·사이즈·수량·금액, 수령인 이름·전화번호·우편번호·주소·메모, 주문·처리 시각 및 취소·반품 처리 이력이 DB에 저장되는 구조입니다. 시험 시 이 필드에도 가상정보만 사용해야 합니다. 실제 카드번호를 입력받거나 자동 환불 송금을 수행하지 않습니다.

### 5. 데이터 저장과 사용 서비스
Vercel은 쇼핑몰 서버와 웹페이지를 실행합니다. Clerk는 인증과 로그인 세션을 제공합니다. Turso는 회원·주문·운영 설정을 저장하는 DB 서비스입니다. Cloudflare R2는 관리자가 업로드하는 상품·배너 사진과 이미지 업로드 처리에 사용합니다. 사진에 타인의 얼굴, 신분증, 주소 또는 연락처가 포함되지 않도록 확인하세요.
인증·서버·DB·이미지 서비스의 실제 계약 주체, 저장 지역, 국외 이전에 해당하는 사항 및 세부 제공 조건은 운영 개통 전에 실제 계정 설정과 각 서비스의 조건을 확인하여 안내해야 합니다. 아직 확인하지 않은 지역이나 계약 내용을 임의로 기재하지 않습니다. 이 사이트는 공개 여부와 별도로 회원 본인의 정보와 관리자 권한을 서버에서 구분합니다.

### 6. 보유와 삭제
테스트 데이터는 기능 확인 목적으로 저장됩니다. 현재 자동 회원탈퇴·개인정보 삭제·기간 만료 삭제 기능은 구현되어 있지 않습니다. 테스트 종료 시 담당자가 Clerk 계정 데이터, 쇼핑몰 DB 및 업로드 이미지를 각각 확인하여 필요한 삭제를 별도로 수행해야 합니다. 정해지지 않은 자동 삭제 기간이나 자동 백업을 약속하지 않습니다. 실제 운영 시 법령상 보존 대상과 기간, 삭제 절차를 확정한 방침으로 교체해야 합니다.

### 7. 본인 정보 확인과 수정
인증된 본인 계정의 이름·연락처 및 주문을 내 계정에서 확인할 수 있습니다. 로그인 비밀번호 관리와 재설정은 Clerk 로그인 화면을 이용합니다. 개인정보 삭제 등 화면에서 제공하지 않는 요청은 테스트 담당자에게 별도 전달해야 합니다. 아래 예시 이메일과 연락처는 요청을 받는 실제 고객센터가 아닙니다.

### 8. 접근 보호와 한계
서버는 확인된 로그인 신원과 요청 출처를 검사하며, 회원은 본인의 정보와 주문만 조회·수정할 수 있습니다. 관리자 화면과 저장·업로드 API도 서버 권한 검사를 사용합니다. 비밀키를 브라우저나 Git에 공개하지 않습니다. 이 안내는 자동 백업·상시 감시 또는 보안상의 모든 위험이 제거되었다는 보증이 아닙니다.

### 9. 아동의 정보
이 테스트에서 만 14세 미만의 실제 이용자를 모집하지 않습니다. 연령 확인 및 법정대리인 동의 기능은 아직 제공하지 않습니다. 아동의 실제 개인정보를 입력하지 마세요.
